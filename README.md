# Kena Cleaning Company website

Static 5-page site: index, services, portfolio, about, contact.

## Host on GitHub Pages
1. Create a repo and upload ALL files in this folder to the root.
2. Repo Settings > Pages > Deploy from branch > main / (root).
3. Your site goes live at https://YOUR-USERNAME.github.io/YOUR-REPO/
4. Replace YOUR-USERNAME/YOUR-REPO in robots.txt and sitemap.xml.
